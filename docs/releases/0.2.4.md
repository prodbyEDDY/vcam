# VCam 0.2.4 — Daily updates / Обновления раз в сутки

VCam now checks for updates at most once every 24 hours. The last attempt is saved on this computer, so restarting VCam does not cause another check. Failed checks retry the next day. Corrupt or future timestamps cannot indefinitely prevent updates.

Updates still download in the background and install after you close VCam. An active camera session is not restarted. The Russian and English interface from 0.2.3 is included.

Русский: проверка обновлений теперь раз в сутки. Время последней попытки сохраняется между запусками, в том числе при ошибке сети. Обновление загружается в фоне и устанавливается после закрытия VCam.

Windows 10/11 x64. Free beta; the installer remains unsigned. Versions 0.2.1 and newer can update automatically; earlier versions require this installer once.
