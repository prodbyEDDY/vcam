# VCam 0.2.2 — исправление значков Windows

- Ярлыки на рабочем столе и в меню «Пуск» теперь используют отдельный файл с фиолетовой V. Старый значок камеры, сохранённый Windows для `VCam.exe`, больше не используется ярлыками.
- Существующие ярлыки обновляются и при установке поверх старой версии, и при автоматическом обновлении. Удалённые пользователем ярлыки при автообновлении не восстанавливаются.
- Значки установщика и удаления приложения заданы явно. Идентификатор окна совпадает с идентификатором ярлыков.

Установите `VCam-Setup-0.2.2-x64.exe` поверх текущей версии. Предварительное удаление и очистка кэша Windows не нужны. VCam 0.2.1 также получит этот выпуск через встроенную проверку обновлений.
