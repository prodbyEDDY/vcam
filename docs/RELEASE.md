# VCam 0.2.1 — Windows beta

Обновление интерфейса: iPhone передаёт изображение из Safari, а VCam для Windows создаёт виртуальную камеру для программ с поддержкой DirectShow.

## Изменения 0.2.1

- Обновлённые тексты и оформление сайта, новый мокап рабочего места с человеком в кадре.
- Сканирование QR камерой прямо на странице подключения; ручной код остаётся доступен.
- Упрощённое главное окно Windows: иконка, кнопка QR и подсказка про Wi-Fi.
- Исправлено быстрое меню качества в шапке приложения.
- Проверка GitHub Releases каждые 60 минут, загрузка обновления в фоне и установка после закрытия VCam. Трансляция не перезапускается ради обновления.
- Мастер установки больше не запускает приложение по нажатию «Готово»: эта кнопка закрывает мастер без ожидания запуска VCam. Открой приложение ярлыком или через меню «Пуск».
- Фиолетовая V используется в приложении, установщике, ярлыках и значках сайта; после установки обновляется кэш значков оболочки.

**С версий 0.2.0 и ниже нужно один раз установить 0.2.1 вручную.** В них ещё нет автообновления. При установке обновлений Windows может запросить права администратора. Сертификата подписи издателя пока нет.

## Установка

1. Скачайте `VCam-Setup-0.2.1-x64.exe` и установите приложение. Регистрация камеры требует прав администратора.
2. Подключите компьютер и iPhone к одной сети Wi-Fi.
3. Откройте VCam, нажмите «Показать QR-код» и отсканируйте QR камерой телефона.
4. Откройте QR-ссылку в Safari и разрешите доступ к камере. Подключение начнётся автоматически. Вместо QR можно открыть сайт на телефоне и ввести код из Windows-приложения.
5. Выберите **VCam** в OBS, Zoom или другом приложении, которое поддерживает виртуальные DirectShow-камеры. При необходимости перезапустите его после установки.

Веб-версия: https://vcam.prodbyeddy.chatgpt.site

## Возможности

- Одноразовый QR, прямой зашифрованный WebRTC-видеопоток, без установки на iPhone.
- Переключение передней/задней и доступных браузеру камер с компьютера.
- Проверка 720p30, 1080p30/60 и 4K30/60; в списке только подтверждённые камерой сочетания.
- Зум камеры при наличии API; отдельно обозначенный цифровой зум.
- Поворот, отражение, сетка, пауза; дополнительные настройки фокуса, экспозиции, баланса белого и фонарика при поддержке браузером.
- Системная камера VCam, 64- и 32-битные DirectShow-компоненты внутри установщика. OBS устанавливать не нужно.

## Проверено

- Быстрое меню качества: открытие списка и применение 720p / 1080p на передающей камере.
- Сканер: декодирование настоящего QR из тестового видеопотока, одноразовый вход, остановка камеры сканера перед трансляцией.
- Планировщик обновлений: почасовая проверка, повтор после сетевой ошибки, отсутствие повторной загрузки и принудительного перезапуска.

- Автоматический старт по QR, повторный QR в той же вкладке и ручной код.
- Изменяющиеся кадры 1920×1080 через DirectShow при свёрнутом Windows-окне.
- Лендинг, метаданные, помощь, скачивание, отправка ссылки и мобильная компоновка.

- Автоматическое подключение двух Chromium-клиентов с искусственной камерой: QR, видеопоток, поворот, отражение, удалённая пауза/продолжение, освобождение камеры.
- Тесты прав доступа к сессии, одноразового QR, истечения срока, ограничения запросов и очистки.
- Нативная передача кадра 1920×1080 через DirectShow с проверкой цветов.
- Полный путь через Windows-приложение: Chromium-камера → WebRTC 1920×1080 → изолированный Electron preload → IPC → C++ bridge → DirectShow. Получен непустой видеокадр в приложении-получателе.

## Ограничения beta

- На физическом iPhone 14 Pro Max эта сборка ещё не проверена. Safari может не предоставлять все объективы и ручные настройки штатной камеры.
- Телефон должен оставаться с открытой страницей Safari. Фоновая камера и съёмка при блокировке экрана не обещаются.
- Доступ к сайту требует интернета. Ретранслятор TURN в этот выпуск не входит: используйте одну локальную сеть без изоляции клиентов. После разрыва может понадобиться новый QR.
- Выбранный режим захвата, фактически принятый поток и формат камеры в OBS/Zoom — разные параметры. Частота и разрешение зависят от сети, процессора и приложения-получателя; 4K60 не гарантируется.
- Виртуальная камера использует DirectShow. Совместимость с приложениями, принимающими только Media Foundation, включая отдельные версии Windows Camera, не обещается.
- Звук с телефона не передаётся. Это выпуск виртуальной видеокамеры.
- Установщик пока без сертификата издателя; Windows может показать предупреждение неизвестного издателя.

Удаление через настройки Windows также снимает регистрацию виртуальной камеры.
